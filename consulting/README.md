# consulting

Skills for the client-services side of consulting engagements — scoping, tracking, and transitions — independent of any specific delivery platform.

## Skills

### Pre-engagement / scope

- **[discovery-call-prep](discovery-call-prep/SKILL.md)** — Prepares a structured discovery call agenda and question list for a new client engagement.
- **[proposal-scope-estimate](proposal-scope-estimate/SKILL.md)** — Turns discovery/requirements notes into a scoped proposal with effort estimates.
- **[sow-draft-generate](sow-draft-generate/SKILL.md)** — Drafts a Statement of Work from discovery notes or a requirements doc.
- **[change-order-draft](change-order-draft/SKILL.md)** — Drafts a change order when scope shifts mid-engagement.

### Ongoing engagement tracking

- **[meeting-notes-action-extract](meeting-notes-action-extract/SKILL.md)** — Converts raw meeting notes/transcripts into decisions and owned, dated action items.
- **[status-report-generate](status-report-generate/SKILL.md)** — Generates a client-facing status report from raw internal activity.
- **[risk-register-track](risk-register-track/SKILL.md)** — Maintains a project risk register and flags stale or unowned entries.

### Transitions

- **[client-context-switch](client-context-switch/SKILL.md)** — Reconstructs a compact briefing for a specific client when switching back to it among multiple concurrent engagements.
- **[handoff-doc-generate](handoff-doc-generate/SKILL.md)** — Produces a project handoff/knowledge-transfer doc when rolling off or transitioning an engagement.
- **[engagement-retro-facilitate](engagement-retro-facilitate/SKILL.md)** — Runs a structured end-of-engagement retrospective and converts it into action items.
